# Agent Instructions — Information Management Kiosk

## Project Context

This is the capstone project repository for an **Information Management Kiosk with IoT-Assisted Document Request Services**.

## Agent Workflow

When working on this project, agents must:

1. **Read docs/ first** — understand requirements before coding
2. **Check docs/tasks/** — know what's in progress and what's next
3. **Consult decisions/** — understand why things were built a certain way

## File Roles

| Folder | Purpose |
|--------|---------|
| `docs/` | What the system SHOULD be |
| `docs/tasks/` | What we are currently BUILDING |
| `tests/` | What the system MUST PROVE |
| `decisions/` | Why we made this choice |
| Git | What the code ACTUALLY changed |

## Session Protocol

At session start:
1. Read this file
2. Check `decisions/decision-log.md` for context

At session end:
1. Update task status if any work was done
2. Log any new decisions
3. Commit with descriptive message
