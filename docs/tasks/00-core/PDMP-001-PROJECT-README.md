# Overview

The **Information Management System with IoT-Assisted Document Request Services Kiosk for Barangay San Manuel** is a digital platform designed to modernize barangay document request services by combining a web-based Information Management System (IMS) with an IoT-assisted self-service kiosk.

The project aims to reduce manual processing, improve service efficiency, centralize resident records, and provide residents with a faster and more convenient way to request barangay documents.

This repository contains both the development process (PDMP) and the implementation of the system.

---

# Objectives

The project aims to:

- Digitize barangay resident records.
- Simplify document request processing.
- Reduce manual encoding.
- Improve staff efficiency.
- Provide a self-service kiosk for residents.
- Integrate RFID for resident identification.
- Capture resident photos through the kiosk webcam.
- Maintain accurate request history.
- Produce reports for barangay personnel.
