# Objective

Initialize the Angular frontend application that will serve as the primary user interface for the **Information Management System with IoT-Assisted Document Request Services Kiosk for Barangay San Manuel**.

The project should follow Angular best practices and provide a scalable architecture for future feature development.

---

# Background

The frontend will power both the administrative web application and, with appropriate UI adaptations, the kiosk interface. This task establishes the Angular workspace, installs dependencies, and prepares the application for development.
