# 03 — Minimum Viable Product (MVP)

# Information Management System with IoT-Assisted Document Request Services Kiosk for Barangay San Manuel

**Project Type:** Capstone Project  
**Client:** Barangay San Manuel  
**Frontend Framework:** Angular  
**System Type:** Self-Service Kiosk + Barangay Staff Information Management System  
**MVP Version:** 2.0  
**Status:** Requirements Refinement

---

# 1. Purpose

This document defines the Minimum Viable Product (MVP) of the project.

The MVP establishes the smallest complete version of the system that can demonstrate the project's core purpose:

> **Digitalize the Barangay document request process through an IoT-assisted self-service kiosk while maintaining the existing Barangay staff processing, payment, approval, and release workflow.**

The MVP prevents the project from expanding into a complete Barangay management system.

---

# 2. MVP Goal

The MVP must demonstrate a complete and verifiable document-request workflow:

```text
Resident
   ↓
RFID Identification
   ↓
Resident Information
   ↓
Service Selection
   ↓
Request Information
   ↓
Request Submission
   ↓
Barangay Staff Processing
   ↓
Payment / Payment Recording
   ↓
Approval
   ↓
Document Preparation
   ↓
Release
