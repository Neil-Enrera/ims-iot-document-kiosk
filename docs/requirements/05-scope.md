# 2. Scope Statement

The project will develop an:

> **Information Management System with IoT-Assisted Document Request Services Kiosk for Barangay San Manuel**

The system will provide a self-service kiosk where registered residents can use an RFID-enabled Barangay ID to identify themselves and initiate supported document requests.

The request will then be processed through a Barangay staff management system following the Barangay's established workflow.

The system will focus primarily on:

```text
Resident Identification
        ↓
Resident Information Retrieval
        ↓
Document/Service Selection
        ↓
Requirements
        ↓
Request Information
        ↓
Request Submission
        ↓
Staff Processing
        ↓
Payment Where Applicable
        ↓
Approval
        ↓
Document Release
