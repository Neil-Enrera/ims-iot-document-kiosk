---

# 1. Purpose

This document defines the functional and non-functional requirements of the proposed Information Management System with IoT-Assisted Document Request Services Kiosk for Barangay San Manuel.

The requirements are based on:

1. The approved project overview
2. The proposed kiosk concept
3. The actual workflow information provided by Barangay San Manuel
4. The Barangay Captain interview

The purpose of this document is to establish a clear and controlled scope before implementation.

---

# 2. Project Goal

The goal of the system is to digitalize the Barangay's document request process through a self-service kiosk and a staff-side information management system.

The system should reduce manual encoding and provide a more organized way of receiving, processing, approving, and tracking document requests.

The system should support the existing Barangay workflow rather than unnecessarily replacing the roles of Barangay personnel.
